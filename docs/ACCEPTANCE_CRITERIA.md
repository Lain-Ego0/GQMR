# GQMR 量化验收标准

> 状态：冻结  
> 参考机：Ubuntu 24.04.3、Intel Core i7-12650H、16 GiB RAM

## 1. 数值正确性

| ID | 项目 | 通过标准 |
|---|---|---|
| NUM-001 | `wxyz↔xyzw` 往返 | 10 万随机单位四元数，最大绝对误差 `<1e-6` |
| NUM-002 | 旋转矩阵/四元数往返 | 测地角误差 `<1e-6 rad` |
| NUM-003 | SLERP | 单位范数误差 `<1e-6`，无符号长弧跳变 |
| NUM-004 | Go2/B2 FK | golden body/site 位置误差 `<1e-5 m` |
| NUM-005 | Jacobian | 对 100 个合法姿态做中心有限差分，相对误差 `<1e-4` |
| NUM-006 | 速度 | 解析正弦轨迹 RMSE `<1%`，旋转恒角速度 RMSE `<1%` |

Golden 不允许只由被测实现首次生成。至少包含解析链式模型、人工固定姿态和固定上游模型版本的独立数据。

## 2. 数据协议

| ID | 项目 | 通过标准 |
|---|---|---|
| DAT-001 | NPZ 安全加载 | object dtype、pickle、非法 JSON、重复名全部拒绝 |
| DAT-002 | 时间戳 | 重复、倒序、NaN 和非正间隔全部拒绝 |
| DAT-003 | 模型绑定 | hash 不匹配禁止回放和导出 |
| DAT-004 | 无效帧 | 默认导出拒绝；显式修复或排除后才允许 |
| DAT-005 | 工程保存 | 注入故障后原文件或 `.bak` 至少一个可打开 |
| DAT-006 | 缓存 | 输入、配置、插件或算法版本改变时缓存必失效 |

## 3. 重定向质量

固定测试集包含 MIT 合成 walk、trot、pace、turn 和退化/缺失点案例。历史 CC BY-NC 数据只生成本地附加报告。

| ID | 项目 | 通过标准 |
|---|---|---|
| RET-001 | 关节限位 | 0 个硬限位违规帧 |
| RET-002 | 快速模式有效率 | `>=99.5%` |
| RET-003 | 足端目标 | 有效帧世界系 RMSE `<=0.03 m` |
| RET-004 | 四元数 | 范数误差 `<1e-5`，相邻帧无符号跳变 |
| RET-005 | 退化骨架 | 不崩溃，状态码正确，输出不被标为正常 |
| RET-006 | 高质量接触 | 平均接触滑移比快速模式降低 `>=50%` |
| RET-007 | 循环 | 根旋转 `<1°`，关节最大差 `<0.03 rad` |
| RET-008 | 根旋转修正 | yaw 修正不超过配置硬边界，roll/pitch 投影连续，不产生硬裁剪跳变 |
| RET-009 | 真实动作预处理 | 修复后数组有限，骨长异常可定位，地面拟合和中性区间记入元数据 |

## 3.1 局部修复和诊断联动

| ID | 项目 | 通过标准 |
|---|---|---|
| REP-001 | 选区隔离 | 修复后选区外根位置、根旋转、关节、接触和状态逐字节不变 |
| REP-002 | 边界连续 | 根位置跳变 `<2 mm`，根旋转 `<0.5°`，关节 `<0.02 rad` |
| REP-003 | 根高度 | 局部偏置符号、大小和过渡可预测，不新增穿地或非有限数值 |
| REP-004 | 幅度缩放 | 根位移、根倾斜和肢体目标分组可控，系数有显式边界 |
| REP-005 | 局部平滑 | 选区内指定平滑指标改善，选区外不变，边界导数不恶化超过阈值 |
| REP-006 | 足端锁定 | 指定足接触滑移降低 `>=50%`，且无新增自碰撞或硬限位违规 |
| REP-007 | 可重现性 | 同一输入、选区和 `LocalRepairConfig` 产生相同内容 hash |
| REP-008 | 撤销重做 | 100 次修复撤销/重做后 hash 与预期一致 |
| DIA-001 | 问题分段 | 连续或短间隔问题帧合并结果稳定，不跨越长正常片段 |
| DIA-002 | 一键选区 | 任意问题帧在两次用户操作内变成包含缓冲帧的修复区间 |

## 3.2 质量门禁

| ID | 项目 | 通过标准 |
|---|---|---|
| QGT-001 | 一致性 | CLI、GUI 和导出前检查对同一动作得到相同结果 |
| QGT-002 | 状态 | 每项仅为 `pass/warn/fail/not_applicable`，无隐式通过 |
| QGT-003 | 前后对比 | 修复结果包含 before/after/delta，退化超阈值时不默认接受 |
| QGT-004 | 导出阻断 | 存在核心 `fail` 时默认拒绝导出；强制导出必须记录失败项 |
| QGT-005 | 可定位性 | 每个 `fail` 包含具体帧或问题片段及建议操作 |

## 6. 发布门槛

- P0/P1 缺陷为 0。
- 所有必选验收 ID 通过；跳过必须有负责人、原因和截止版本。
- wheel/sdist、离线资产包和示例工程通过许可证扫描。
- 干净 Ubuntu 24.04 虚拟机完成安装、Go2 资产安装、CLI 闭环、GUI smoke test 和 AMP 往返。
- schema、stream protocol 或插件 API 破坏兼容时必须提升对应主版本。
